# YarVpn — сайт yarvpn.best

Статический сайт (без сборки): чёрный фон, оранжевый акцент, шрифт Unbounded, живой волновой фон и карта серверов с самолётиком.
Хостинг — GitHub Pages, домен из файла `CNAME`.

## Публикация (GitHub Pages)
**Settings → Pages**: Branch `main`, папка `/ (root)`. Любой коммит в `main` публикуется автоматически.
Бот сам подтягивает эту же версию сайта на свой сервер (раз в 3 часа и при запуске) — загружать вручную ничего не нужно.

## Личный кабинет (`/cabinet/`)
Вход: логин — Telegram ID, пароль — случайный (12 знаков) из «Профиль → Вход на сайт» или свой (любой, 4–16 знаков). В кабинете — баланс, подписка, устройства, друзья, история, пополнение через Crypto Pay и TON, смена пароля.

Кабинет всегда открывается на сайте. Страница берёт данные у бота по HTTPS-адресу `https://cab.yarvpn.best:25273` (запасной — `https://api.yarvpn.best:25273`; список — в `api.json`, поле `api`: страница проверяет все адреса сразу и берёт тот, что ответил). Сертификат Let's Encrypt бот получает и продлевает сам, см. README бота. Если страницу отдал сам бот (тот же адрес) — работает напрямую. Поле `cabinet` в `api.json` — необязательный запасной адрес (по умолчанию пусто: никуда не перекидывает; при недоступном API показывается сообщение с кнопками «Повторить» и «Проверить связь»).

Токены и пароли в этом репозитории не хранятся — они только в `config.py` бота.
