# YarVpn — сайт yarvpn.best

Статический сайт (GitHub Pages, домен из `CNAME`). Без сборки и зависимостей: правишь файлы — пушишь — всё обновилось.

```
index.html              страница целиком: тексты, SEO-разметка, список серверов
404.html                страница «не найдено»
assets/css/main.css     весь дизайн (цвета и радиусы — переменные в :root)
assets/js/main.js       меню, появление блоков, анимированный фон-«угли», демо-чат
assets/js/map.js        карта серверов (canvas)        assets/js/mapdata.js — сетка суши (генерируется)
assets/js/cabinet.js    вход через Telegram-бота и личный кабинет
assets/js/qr.js         QR-код для входа (qrcode-generator, MIT)
assets/fonts/           Geologica, Onest, JetBrains Mono (свои файлы, без Google Fonts)
assets/img/             favicon, иконки, og.png (картинка для соцсетей)
robots.txt, sitemap.xml, site.webmanifest, favicon.ico
```

## Что править чаще всего

**Серверы на карте** — в `index.html` список `<ul id="srvList">`: одна строка `<li>` = один сервер
(`data-lat`/`data-lon` — координаты столицы, `data-dir` — куда ставить подпись у точки `r/l/t/b`, `data-main="1"` — основной узел).
Добавил/убрал `<li>` — карта и список обновились сами.

**Тарифы и цены** — секция `#pricing` в `index.html` (и продублированы в JSON-LD в `<head>` и в FAQ — держи в синхроне).

**Вход в кабинет** — адрес API бота в `<meta name="yarvpn-api">` (`index.html`, в `<head>`). Нужен HTTPS-адрес,
проксирующий на порт бота; подробности — в README бота, раздел «Вход на сайт». Пустое значение отключает кабинет.

**Цвет акцента** — `--ember` в начале `assets/css/main.css`.

## SEO — что сделано и что осталось сделать руками

Сделано: осмысленные `title`/`description`, один `h1`, семантические заголовки, тексты в HTML (не в JS), Open Graph/Twitter,
canonical, JSON-LD (Organization, WebSite, Service с тарифами, FAQPage), `robots.txt`, `sitemap.xml`, быстрая загрузка
(≈230 КБ, свои шрифты, без внешних скриптов), адаптивность, `prefers-reduced-motion`.

Осталось (без этого в топ не выйти, это делается только владельцем сайта):
1. Добавить сайт в **Яндекс Вебмастер** и **Google Search Console**, вставить коды подтверждения в `<head>` (заготовка там закомментирована),
   отправить `https://yarvpn.best/sitemap.xml`. Для российской аудитории Яндекс важнее Google.
2. В Вебмастере указать регион сайта и заполнить «Информацию об организации/сайте».
3. Внешние ссылки: упоминания в Telegram-каналах, каталогах, профилях; конкурентные запросы вроде «впн» без ссылочной массы не растут.
4. После публикации проверить сайт в «Проверке структурированных данных» и «Анализаторе страниц» Вебмастера.
