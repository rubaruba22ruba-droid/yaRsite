# YarVpn — сайт yarvpn.best

Статический сайт (без сборки): чёрный фон, оранжевый акцент, шрифт Unbounded, живой волновой фон и карта серверов с самолётиком.
Хостинг — GitHub Pages, домен из файла `CNAME`.

## Публикация (GitHub Pages)
**Settings → Pages**: Branch `main`, папка `/ (root)`. Любой коммит в `main` публикуется автоматически.

## Вход
Кнопки «Войти» просто открывают бота в Telegram (кабинет живёт в боте, раздел «Профиль»). Никакого API и Cloudflare Worker для сайта не нужно.

## Мини-апп рулетки
`miniapp/index.html` (копия — в репозитории YarVpn). Рулетке нужен HTTPS-адрес бота (Telegram не пускает мини-апп на обычный http): его нужно вписать в `api.json`.
Пока поле `api` пустое, мини-апп показывает экран «Рулетка скоро откроется».
