# YarVpn — сайт yarvpn.best и мини-апп рулетки

Статический сайт (GitHub Pages, домен из `CNAME`). Без сборки и зависимостей: правишь файлы — коммитишь — всё обновилось.

```
index.html              страница целиком: тексты, SEO-разметка, список серверов
404.html                страница «не найдено»
api.json                адрес HTTPS-прокси к боту (вход на сайте и рулетка читают его сами) — см. «Вход и рулетка»
worker/                 Cloudflare Worker — HTTPS-прокси к боту (yarvpn-api-proxy.js)
miniapp/index.html      мини-апп «Ежедневная рулетка» для Telegram (боевой, без демо)
components/ui/          sss.tsx + demo.tsx — тот же ASCII-фон как React/shadcn-компонент (сайт их не использует)
assets/css/main.css     весь дизайн (цвета — переменные в :root)
assets/js/main.js       навигация, 3D-наклон, появление блоков, демо подключения и диалога с ботом
assets/js/ascii-bg.js   фон: ASCII-видео + запасная ASCII-анимация
assets/js/globe.js      3D-глобус с серверами        assets/js/mapdata.js — сетка суши (генерируется)
assets/js/cabinet.js    вход через Telegram-бота и личный кабинет
assets/js/qr.js         QR-код для входа (qrcode-generator, MIT)
assets/fonts/           Onest, Geologica, JetBrains Mono (свои файлы, без Google Fonts)
assets/img/             favicon, иконки, og.png (картинка для соцсетей)
robots.txt, sitemap.xml, site.webmanifest, favicon.ico
```

## Правило проекта: данные не выдумываются

Все цифры и тексты на сайте взяты из проекта. Если данных нет — блок их не показывает.

| Что на сайте | Откуда |
|---|---|
| Тарифы (7 дней — 39 ₽ / 120 ГБ, 1 месяц — 79 ₽ / 500 ГБ, 3 месяца — 199 ₽ / 1500 ГБ), до 3 устройств | `config.py` бота (`PLANS`) и прежний сайт |
| «Популярный выбор» у тарифа «1 месяц» | был на прежнем сайте |
| Докупка устройств (+1 — 49, +3 — 99, +10 — 209 ₽, «ХИТ» у +10) и трафика (+50 — 49, +250 — 199, +500 — 399 ₽) | `DEVICE_PACKS`, `GB_PACKS` |
| Пробный период: 3 дня, 10 ГБ, 1 устройство | `TRIAL_*` |
| Оплата: TON, Telegram Stars, криптовалюта, баланс | прежний сайт, кнопки оплаты бота |
| Реферальная программа: 10 ₽ за друга (до 15), с 16-го — 20% | `REFERRAL_*` |
| Ежедневная рулетка: билет в 14:00 МСК, призы | `ROULETTE_*` |
| Серверы: Финляндия, США, Испания, Швеция, Турция, Албания (столицы — Хельсинки, Вашингтон, Мадрид, Стокгольм, Анкара, Тирана) | список, который назвал владелец проекта |
| Приложения для подключения (Happ, v2rayNG, v2rayN) | кнопки «Инструкция» в боте |
| Тексты блоков, вопросы FAQ | прежний сайт и тексты бота |
| Ссылки: бот, канал, поддержка, почта, документы | прежний сайт и config.py |

Чего на сайте **нет**, потому что этого нет в проекте: пинга, аптайма, загрузки серверов, статуса «онлайн», скорости в цифрах.
Дуги на глобусе — оформление (связи между узлами), а не измерения. Карточка в первом экране показывает пробный период,
а после входа — живые данные подписки пользователя из бота.

## Что править чаще всего

**Серверы на глобусе** — в `index.html` список `<ul id="srvList">`: одна строка `<li>` = один сервер
(`data-lat`/`data-lon` — координаты столицы, `data-dir` — куда ставить подпись у точки `r/l/t/b`, `data-main="1"` — центр дуг).
Добавил/убрал `<li>` — глобус и список обновились сами. Тексты про «шесть стран» (заголовок, лента столиц, FAQ, JSON-LD) правятся отдельно.

**Тарифы и цены** — секция `#pricing` в `index.html` (и продублированы в JSON-LD в `<head>` и в FAQ — держи в синхроне).

**Фон** — ASCII-видео из `index.html` (`<div class="ascii">`). Если оно выглядит не так, как ожидалось, добавь к адресу сайта:
`?bg=invert` — если видео тёмное на светлом, `?bg=raw` — без цветной тонировки, `?bg=fallback` — только запасная анимация.
Подошло — впиши то же в `data-tone="light"` / `data-tint="off"` у `<div class="ascii">`. Яркость — `--ascii-o` в `assets/css/main.css`.

**Цвета** — переменные в начале `assets/css/main.css` (`--violet`, `--cyan`, `--accent` и т. д.).

## Вход в кабинет и рулетка

Сайт и мини-апп открываются по HTTPS, а бот отвечает по `http://…:порт` — браузер такое запрещает («mixed content»),
поэтому вход и рулетка не работают. Решение — бесплатный Cloudflare Worker (`worker/yarvpn-api-proxy.js`), который принимает
HTTPS и пересылает запрос боту:

1. Зарегистрируйся на cloudflare.com → **Workers & Pages** → **Create** → **Create Worker** → назови `yarvpn-api` → **Deploy**.
2. **Edit code** → удали всё → вставь содержимое `worker/yarvpn-api-proxy.js` → **Deploy**. (Дата совместимости — от 2024-09-02; в новых воркерах так и есть.)
3. Скопируй адрес воркера (`https://yarvpn-api.<твой-логин>.workers.dev`) и впиши его в поле `"api"` файла **`api.json`** в этом репозитории.
4. Проверка: открой `<адрес воркера>/health` — должно быть `{"ok":true,…}`. Затем — вход на сайте и рулетка в боте.

Адрес бота зашит в воркере (`DEFAULT_UPSTREAM`) или задаётся переменной `UPSTREAM` в его настройках. Воркер пропускает только
`/api/web/*` и `/api/roulette/*`. Мини-апп читает тот же `api.json` с `https://yarvpn.best/api.json`, поэтому править его отдельно не нужно.

## SEO — что сделано и что осталось сделать руками

Сделано: осмысленные `title`/`description`, один `h1`, семантические заголовки, тексты в HTML (не в JS), Open Graph/Twitter,
canonical, hreflang, JSON-LD (Organization, WebSite, Service с тарифами, FAQPage — в т. ч. «В каких странах есть серверы»),
`robots.txt`, `sitemap.xml`, быстрая загрузка (свои шрифты, без внешних скриптов, кроме ASCII-видео), адаптивность, `prefers-reduced-motion`.

Осталось (без этого в топ не выйти, это делается только владельцем сайта):
1. Добавить сайт в **Яндекс Вебмастер** и **Google Search Console**, вставить коды подтверждения в `<head>` (заготовка там закомментирована),
   отправить `https://yarvpn.best/sitemap.xml`. Для российской аудитории Яндекс важнее Google.
2. В Вебмастере указать регион сайта и заполнить «Информацию об организации/сайте».
3. Внешние ссылки: упоминания в Telegram-каналах, каталогах, профилях; конкурентные запросы вроде «впн» без ссылочной массы не растут.
4. Ускорить индексацию (IndexNow, Яндекс и Bing): в файле `f38c980788ae6acb22f503d4636a2084.txt` лежит ключ сайта. После публикации один раз открой в браузере
   `https://yandex.com/indexnow?url=https://yarvpn.best/&key=f38c980788ae6acb22f503d4636a2084&keyLocation=https://yarvpn.best/f38c980788ae6acb22f503d4636a2084.txt` — Яндекс получит сигнал об обновлении.
5. После публикации проверить сайт в «Проверке структурированных данных» и «Анализаторе страниц» Вебмастера.
