# YarVpn — сайт yarvpn.best и мини-апп рулетки

Готовый статический сайт (GitHub Pages). Ничего собирать и устанавливать не нужно: загрузил файлы — работает.

## Что где лежит
```
index.html            сайт целиком (тексты, тарифы, SEO)
api.json              адрес прокси к боту — нужен для входа в кабинет и рулетки (см. ниже)
worker/               код Cloudflare Worker (прокси) — копируется в Cloudflare одним куском
miniapp/index.html    мини-апп «Ежедневная рулетка» (его же кладём в репозиторий YarVpn)
assets/               стили, скрипты, шрифты, картинки
tools/hand-src/       исходники 3D-руки (нужны только разработчику)
```

## Как загрузить сайт (без программирования)
1. GitHub → репозиторий **yaRsite** → **Add file → Upload files**.
2. Распакуй архив `yarvpn_site.zip` и перетащи **всё содержимое** (папки и файлы) в окно. Подтверди замену. Внизу **Commit changes**.
3. **Settings → Pages**: Source — ветка `main`, папка `/ (root)`. Домен yarvpn.best подхватится из файла `CNAME`.

## Чтобы заработали вход в кабинет и рулетка (5 минут, один раз)
Сайт открывается по HTTPS, а бот отвечает по `http://…:порт` — браузер такое блокирует. Лечится бесплатным Cloudflare Worker:
1. cloudflare.com → регистрация → **Workers & Pages → Create → Create Worker** → имя `yarvpn-api` → **Deploy**.
2. **Edit code** → удали всё → вставь содержимое `worker/yarvpn-api-proxy.js` → **Deploy**.
3. Скопируй адрес воркера (`https://yarvpn-api.твой-ник.workers.dev`).
4. В GitHub открой файл `api.json` → карандаш → вставь адрес между кавычками в `"api": ""` → **Commit**.
5. Проверка: `адрес-воркера/health` показывает `{"ok":true…}`. Дальше вход на сайте и рулетка работают.

Мини-апп сам читает `https://yarvpn.best/api.json`, править его отдельно не нужно.

## Мини-апп рулетки
Файл `miniapp/index.html` → в репозиторий **YarVpn** (замени `index.html`). В `config.py` бота `ROULETTE_WEBAPP_URL` уже указывает на него.

## Данные — только из проекта
Тарифы, цены, лимиты, пробный период, рефералка, рулетка, ссылки — из `config.py` бота и прежнего сайта. На сайте нет выдуманных
цифр: ни пинга, ни аптайма, ни списка серверов (локации меняются — актуальный список всегда в боте). Точки и дуги на глобусе — оформление.
