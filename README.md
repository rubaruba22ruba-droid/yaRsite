# YarVpn — сайт yarvpn.best

Статический сайт (без сборки): чёрный фон, оранжевый акцент, шрифт Unbounded, живой волновой фон и карта серверов с самолётиком.
Хостинг — GitHub Pages, домен из файла `CNAME`.

## Публикация (GitHub Pages)
**Settings → Pages**: Branch `main`, папка `/ (root)`. Любой коммит в `main` публикуется автоматически.
Бот сам подтягивает эту же версию сайта на свой сервер (раз в 3 часа и при запуске) — загружать вручную ничего не нужно.

## Личный кабинет (`/cabinet/`)
Вход: кнопка «Войти через Telegram» (страница → бот → «Да, это я» → страница сама открывает кабинет) либо логин (Telegram ID) и пароль из «Профиль → Вход на сайт» (свой — любой, 4–16 знаков). В кабинете — баланс, подписка, устройства, друзья, история, пополнение через Crypto Pay и TON, смена пароля.

Кабинет всегда открывается на сайте. Страница берёт данные у бота по HTTPS-адресу из `api.json` (первый — `https://yarvpn.duckdns.org:25273`: бесплатное имя вне Cloudflare, потому что Cloudflare не пропускает порт 25273; затем `https://cab.yarvpn.best:25273` и `https://api.yarvpn.best:25273`; список — в `api.json`, поле `api`: страница проверяет все адреса сразу и берёт тот, что ответил). Сертификат Let's Encrypt бот получает и продлевает сам, см. README бота. Если страницу отдал сам бот (тот же адрес) — работает напрямую. Поле `cabinet` в `api.json` — необязательный запасной адрес (по умолчанию пусто: никуда не перекидывает; при недоступном API показывается сообщение с кнопками «Запасной вход» (кабинет на адресе сервера, поле `fallback`), «Повторить» и «Проверить связь»; если имя не находится только у этого устройства — страница так и пишет).

Токены и пароли в этом репозитории не хранятся — они только в `config.py` бота.

## Безопасность
- На всех страницах строгая политика CSP (скрипты только свои, без inline; запросы — только к `yarvpn.best`, `cab/api.yarvpn.best` и DoH-диагностике), защита от встраивания в чужие рамки, без внешних скриптов и шрифтов.
- `/.well-known/security.txt` — куда сообщать об уязвимостях: yarsup@proton.me.
- Сессия кабинета хранится в браузере (`localStorage`) и отправляется заголовком `Authorization`, а не cookie — поэтому подделать запрос с чужого сайта нельзя; на сервере хранится только хэш сессии.
- Серверная часть (лимиты, баны, защита от перебора и сканеров) — в боте, см. его README.
- Страница, открытая по `http://`, сама переходит на HTTPS; если у сайта нет действующего сертификата — на запасной HTTPS-адрес бота (`cab.yarvpn.best:25273`, тот же сайт), чтобы не показывать ошибку сертификата.
