# YarVpn — сайт yarvpn.best

Статический сайт (без сборки): чёрный фон, оранжевый акцент, шрифт Unbounded, живой волновой фон и карта серверов с самолётиком.
Хостинг — GitHub Pages, домен из файла `CNAME`.

## Публикация (GitHub Pages)
**Settings → Pages**: Branch `main`, папка `/ (root)`. Любой коммит в `main` публикуется автоматически.

## Личный кабинет (`/cabinet/`)
Вход: логин — Telegram ID, пароль — 8 цифр; оба бот показывает в «Профиль → Вход на сайт». В кабинете — баланс, подписка, устройства, друзья и пополнение через Crypto Pay и TON.

Кабинет и его API обслуживает **сам бот** (бот отдаёт эту же папку `site/` и API `/api/web/*` по одному адресу) — Cloudflare Worker и прокси не нужны.
Если сайт открыт на GitHub Pages, а бот живёт на другом адресе — впишите адрес бота в `api.json` (поле `cabinet`): кнопка «Войти» отправит на `<адрес бота>/cabinet/`.

Токены и пароли в этом репозитории не хранятся — они только в `config.py` бота.
